# V10.10 — PDL-member outbound filtering, escalation clarity, notifications and IST

- PDL-authorized engineer outbound messages are ignored as workload but retained as response evidence.
- Existing imported engineer messages are hidden from operational lists during sync.
- Escalations exclude messages sent by engineers authorized for the same PDL; customer and unauthorized-internal messages remain eligible.
- Notification ribbon is green for responded email and red only for action-required email.
- Marking a notification read no longer falsely marks an email responded.
- UI clock uses 24-hour IST.
- Engineer edit popover opens upward to remain visible at the bottom of long group pages.
- Live email received timestamps remain displayed using the existing IST 24-hour filter.
