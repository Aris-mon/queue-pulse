# V10.11 UI / Search / Notification update

- Dashboard PDL unattended is now `total - responded` for mutually exclusive response coverage.
- PDL detail, monitoring-slot activity and API summary use the same unattended definition.
- Notifications support Unread / Read / All filters, newest date/time ordering, and unread-first ordering.
- Valid PDL-member responses automatically mark linked notifications read.
- Added global search for PDLs, groups, engineers, monitoring slots, executive groups, users, emails and feature/configuration pages.
- Added engineer-member search within Team Management group detail.
- Main workspace now fills the browser viewport and keeps a dedicated central scrollbar.
- Added final dark-mode overrides for tiles, sentiment pills, notifications, search, and team-management controls.
- HPE logo is now served as a transparent GIF while retaining all HPE letters.
- Auto-sync is enabled by default for new installations.
- Clock remains 24-hour IST.
