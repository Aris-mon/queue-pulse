# V10.18.0 — Customer AI Evaluation + Email UX

- Customer sidebar entry now opens Customer AI Evaluation.
- Added real-customer evaluation workspace using 24h default and PDL/sentiment/type/priority filters.
- Live Emails filters are collapsed by default and active filters auto-open.
- Email detail uses a readable message reader with sender role and received timestamp.
- Conversation view is a chronological timeline with explicit received date/time, sender role and workflow state.
- Escalations now show received date/time.
- Notifications show email received time separately from alert creation time.
- Configured engineers remain excluded from customer workload while their responses and operational events remain usable.
